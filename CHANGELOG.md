# Changelog

## Unreleased

- Optional integration with Dxcufgb's Debug Recorder: when it is installed and recording, the glowing cores add their runtime state (Dice So Nice detected and its version, whether the Glowing cores system registered, glow ids, materials and shaders prepared) and breadcrumbs of their main steps to its bug-report file. Nothing changes without it.
- Fixed: once someone rolled Glowing cores dice, other dice with the same look (any player's, any dice system) could glow too.

## 0.1.0

- First version: the **Glowing cores** dice system for Dice So Nice 5, with d4, d6, d8, d10, d12, d20 and d100 that hold a glowing core of light inside the die.
- 16 glows: Ember Heart, Arcane Vortex, Pocket Nebula, Storm Cell, Heartstone, Eclipse, Frost Lattice, Lava Lamp, Plasma Globe, Aurora, Will-o'-Wisps, Arcane Rings, Bubbling Potion, Twin Helix, Radiant Sun and Fairy Lights.
- System options per die type, shown inline in Dice So Nice's Appearance tab once a die type uses Glowing cores: glow, the glow's own or your own colours, intensity, core size, animation speed, pulse (steady, breathe, heartbeat, flicker), rim light, how dark the die body gets, and bloom with realistic lighting. Everyone at the table sees your glow on your rolls.
- Client setting **Glow quality** (low, medium, high).
